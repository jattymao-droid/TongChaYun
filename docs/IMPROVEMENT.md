1. 按 **P16 → P17 → P18 → P19 → P20** 顺序推进；同一阶段内按勾选顺序实现

## 5. 已知约束（改造时注意）

| 约束 | 处理 |
| :--- | :--- |
| `ruoyi-ui` 为 Vue2+ElementUI，`ruoyi-h5` 为 Vue3 | **渲染组件**先在管理端复用；H5 共用 **纯 JS 工具**（校验/归一化），暂不强行跨 Vue 版共享 SFC |
| 公开上传接口不感知单题 | 服务端硬顶统一；单题 `maxSizeMb` 由前端 `beforeUpload` 强制 |
| Java 改动需重启 | `mvn -pl ruoyi-admin -am package -DskipTests` 后重启 jar |
